# L150 ROS SDK

This ROS1 catkin package combines the former `l150_base`, `l150_bringup`, and
`l150_odometry` packages into one hardware SDK.

Build it in a catkin workspace and start all base functions with:

```bash
roslaunch l150_sdk l150_bringup.launch
```

See [README_CN.md](README_CN.md) for the complete usage and interface guide.
